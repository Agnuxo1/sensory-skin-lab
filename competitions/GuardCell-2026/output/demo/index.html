GuardCell: AI can observe.
Only policy can act.

Offline-first industrial workcell demonstrator with an auditable handoff from perception to deterministic behavior-tree control. No direct AI-to-motor pathway. Every action is either explicitly allowed, held, or stopped.

SIMULATED VLM RESULTS. No learned vision model runs in this default demo. The independent color sentinel and fail-closed controller DO run. Use --vlm ollama with an installed gemma3:4b for real local model inference.
CAMERA + INDEPENDENT INTERLOCKS → VLM (INSPECTION ONLY) → TYPE / BBOX / CONFIDENCE GATE → BEHAVIOR TREE → SIMULATED ACTION

# Demonstration video

The H.264 MP4, assets/guardcell_simulation_demo.mp4, illustrates the deterministic simulation decisions. It is generated from the reproducible synthetic scenario fixtures by tools/generate_media.py. It includes no live camera, physical robot or real Gemma model output.

Requirements to re-render media: Python 3.10+, Pillow, OpenCV and an H.264 video encoder. The media generator creates a cover image and an intermediate MPEG-4 video, which can be re-encoded with ffmpeg to H.264.

The public Kaggle notebook runs 27 automated tests and its 1,000-case policy benchmark. Do not interpret virtual hazard handling as certified industrial collision avoidance.
